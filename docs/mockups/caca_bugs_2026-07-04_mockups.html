Como criar seu app da Microsoft

Leva ~4 minutos. Você faz uma vez.

  1. Abra o Portal do Microsoft Entra e vá em Entra ID → Registros de aplicativo → Novo registro.
  2. Dê um nome (ex.: "Hub2You E-mail"). Se for uso interno da empresa, escolha Somente organização atual (single-tenant).
  3. Em URI de Redirecionamento, tipo Web, cole o URL mostrado ao lado. Clique Registrar.
  4. Na Visão geral, copie o ID do aplicativo (cliente) e o ID do diretório (locatário) → campos ao lado.
  5. Em Permissões de API → Microsoft Graph → Delegadas, adicione:
    IMAP.AccessAsUser.AllMail.SendMail.ReadWriteoffline_accessopenidprofileemail
    📅 Calendars.ReadWrite

    📅 Agenda — necessário para o CRM Calendário e as reuniões. Mesmo login: um consentimento libera e-mail + agenda.

  6. Clique Conceder consentimento de administrador e confirme.
  7. Em Certificados e segredos → Novo segredo, copie o Valor (não o ID) → campo "Segredo do cliente".
  8. Volte aqui, cole as credenciais e clique em conectar. Ver documentação →

Antes: os 3 campos ocupavam a largura toda e o lado direito ficava vazio, sem nenhuma ajuda de como criar o app.

Como criar seu cliente do Google

Leva ~5 minutos. Você faz uma vez.

  1. Abra o Google Cloud Console e crie ou selecione um projeto.
  2. Em APIs e serviços → Biblioteca, procure Gmail API e clique Ativar.

    📅 Ative também a Google Calendar API aqui — necessária para o CRM Calendário. Sem ela a agenda dá erro, mesmo com o escopo liberado.

  3. Em Google Auth Platform → Público, escolha tipo Externo e preencha nome + e-mails de contato.
  4. Na etapa Escopos, adicione:
    https://mail.google.com/
    📅 .../auth/calendar

    📅 Agenda — necessário para o CRM Calendário e as reuniões. Mesmo login: um consentimento libera e-mail + agenda.

  5. Em Clientes → Criar cliente, tipo Aplicativo da Web.
  6. Em URIs de redirecionamento autorizados, cole o URL mostrado ao lado. Clique Criar.
  7. Copie o ID do cliente e o Segredo → campos ao lado.
  8. Se o app ficar em Teste, adicione o e-mail da caixa em Usuários de teste. Ver documentação →

Observação: como o sistema também envia e-mail, o escopo é a caixa completa (mail.google.com/) — não basta só leitura.
