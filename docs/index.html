What is Whisker?

Whisker is an open-source customer conversation platform with AI capabilities, RTL-first design, widget theming, and a desktop pet companion. It's built on top of Chatwoot with significant customizations for Persian/multilingual support.

New to Whisker? Start with the Quick Start Guide to get up and running in under 5 minutes.

Quick Start

1. Clone & Install

git clone https://github.com/maddixmhn/Whisker.git
cd Whisker
bundle install && pnpm install

2. Setup Database

bin/rails db:setup
bin/rails db:seed  # Optional: sample data

3. Start Development

pnpm dev
# or
overmind start -f Procfile.dev
Prerequisites: Ruby 3.x, Node 20+, PostgreSQL 14+, Redis 6+

AI Configuration

Whisker supports any OpenAI-compatible API endpoint. Configure your providers in Settings → AI Providers:

# Environment variables (optional)
WHISKER_AI_API_BASE=https://api.ninerouter.com/v1
WHISKER_AI_API_KEY=your-key-here
WHISKER_AI_DEFAULT_MODEL=gpt-4o-mini

Or configure per-account via the dashboard UI — no environment variables needed.
