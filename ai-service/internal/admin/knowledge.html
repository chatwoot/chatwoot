What is it?
How to use a Google Sheet or a data file
  1. In Google Sheets: File → Share → Publish to web, choose the sheet and Comma-separated values (.csv), then Publish. Copy the link it shows and add it here as a data file.
  2. The first row holds the column names. An id column is required: it must stay the same when you edit a row, so the bot updates that answer instead of adding a new one.
  3. For questions and answers use question and answer columns. For longer text use title and content (or text); category and section become the title when there is no title.
  4. JSON Lines works the same way: one object per line with the same names, for example {"id": "product-001", "category": "Price", "section": "Lifetime", "text": "…"}.
  5. Optional start_date and last_day columns (YYYY-MM-DD) limit when the bot may use a row, for example a promotion.
  6. Delete a row and the bot stops using it at once; it is removed for good a week later. Up to 500 rows per file.
