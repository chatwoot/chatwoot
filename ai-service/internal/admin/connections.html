1. Save the token on your computer

Open ~/.zshrc (Mac) in a text editor, add this line, save, and open a new terminal. Typing it into a terminal would leave it in the shell history.

export AISVC_MCP_TOKEN="{{.NewToken}}"

2a. Claude Code

claude mcp add --transport http ai-knowledge {{.URL}} --header "Authorization: Bearer ${AISVC_MCP_TOKEN}"

2b. Codex

Add to ~/.codex/config.toml:

[mcp_servers.ai_knowledge]
url = "{{.URL}}"
bearer_token_env_var = "AISVC_MCP_TOKEN"

Then ask your AI, for example: “List my knowledge base and tell me what is expired or never used.”
