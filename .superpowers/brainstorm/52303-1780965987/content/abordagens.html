Como integrar Viari ↔ Chatwoot?

3 abordagens arquiteturais — cada uma com trade-offs diferentes

A

Plugin Nativo (recomendado)

Segue o padrão da integração Shopify já existente no Chatwoot. Tudo dentro do Chatwoot: painel lateral com abas, modal de orçamento em Vue, Rails como proxy para a API do Viari.


Prós

  • UX completamente integrada — sem sair do Chatwoot
  • Segue padrão já testado (Shopify/Linear)
  • API key armazenada de forma segura no Rails
  • Sem CORS — Rails proxia tudo

Contras

  • Modal de orçamento completo é o maior esforço
  • Precisa de API REST no Viari (a ser criada)
B

Dashboard App (iFrame)

Usa o recurso "Dashboard Apps" nativo do Chatwoot para embutir uma página do Viari num iframe dentro do Chatwoot. O Viari renderiza seu próprio formulário de orçamento.


Prós

  • Reutiliza toda a UI do Viari
  • Menos código no Chatwoot
  • Formulário de orçamento já existe no Viari

Contras

  • iFrame — visual genérico, sem integração com tema Chatwoot
  • Autenticação no iframe é mais complexa (token por conversa)
  • Não cola o texto automático na conversa facilmente
  • Painel lateral não tem abas nativas para dados do cliente
C

Híbrido

Painel lateral nativo (abas de reservas/orçamentos/pagamentos) + botão que abre o Viari em nova aba com o cliente já pré-selecionado para criar o orçamento lá.


Prós

  • Mais simples de implementar
  • Modal de orçamento fica no Viari (já existe)
  • Sidebar nativo integra bem

Contras

  • Troca de aba para criar orçamento — menos fluido
  • Texto do WhatsApp não cola automático no chat

Recomendação

Opção A entrega a experiência completa que você descreveu: sync automático do cliente, painel com abas, modal completo e texto colado na conversa. É mais trabalho, mas é a abordagem certa para o fluxo que você quer.
