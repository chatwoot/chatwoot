🎨 Design do Viari no Chatwoot

Cores e identidade mantidas

Verde-noite (#0D2B2A) no header, teal-aventura (#1D9E75) nos elementos ativos, sol-poente (#EF9F27) para estados de atenção — exatamente a paleta do Viari.

Jornada visual do cliente

Barra de progresso mostra em qual etapa o cliente está: Contato → Orçamento → Sinal → Reserva → Embarque. Atualiza automaticamente conforme os dados mudam no Viari.

🏷️ Etiquetas automáticas de CRM
Evento no Viari → Label no Chatwoot
Cliente criado/vinculado → viari-vinculado
Orçamento enviado → orçamento-enviado
Orçamento aprovado → orçamento-aprovado
Sinal pendente → aguardando-sinal
Reserva confirmada → reserva-confirmada
Pagamento completo → pago-completo
Orçamento expirado/recusado → orçamento-perdido
Passeio concluído → concluído

💡 Como os labels funcionam

Ao carregar o painel, o Chatwoot consulta o Viari e aplica automaticamente as labels correspondentes ao status atual. Labels antigas são substituídas pelas novas conforme a jornada avança — a conversa sempre reflete o estágio real do cliente.
