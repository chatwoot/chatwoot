🐾 ChatPaw Widget Themes

One SDK build — three themes. Pick one; the page reloads with that theme applied to the launcher bubble.

Paw Blob
Default mascot · teal · hop motion on new message
Fox
Warm orange · bounce motion · ding sound
Star
Amber paw accent · tada motion · bell sound

Theme JSON lives in packages/widget-theme/themes/. Pass any of them (or a URL to your own) via chatwootSettings.theme.
