Self-host

Your data. Your server. One command.

# production stack — rails + sidekiq + postgres(pgvector) + redis
$ git clone https://github.com/maddixmhn/Whisker whisker
$ cd whisker
$ cp .env.example .env     # set SECRET_KEY_BASE
$ docker compose -f docker-compose.production.yaml up --build -d

Zero phone-home. Your logs stay on your machine.

About Whisker

Built by the community, for the community.

Whisker is forked from Chatwoot v4.17 and actively maintained as a free, open-source alternative. No venture capital, no enterprise lock-in — just code that works.

How to contribute

Fork the repo, create a feature branch, and open a PR against develop. We follow conventional commits (feat(scope): ...). No CI required — we review manually and test locally. Every contribution matters.
